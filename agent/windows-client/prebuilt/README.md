# Шаблон клиента

Сюда кладётся `Corax.template.exe` — результат `dotnet publish` из [docs/windows-client.md](../../../docs/windows-client.md).

Панель (в том числе в Docker) только вписывает в этот файл адрес сервера и отдаёт его как `Corax.exe`. Исходники здесь не компилируются.

Пока файла нет, кнопка «Клиент для сотрудников» отвечает, что установщика нет. `.dockerignore` пропускает в образ только этот EXE, остальные `*.exe` отбрасываются.

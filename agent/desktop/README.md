# CORAX Agent (Windows 10/11)

Тихий агент инвентаризации. Одно окно в стиле WinUI и иконка в трее. Крестик прячет окно, выход — из меню трея.

Скачивайте сборку со страницы «Сборка агента» в панели CORAX. EXE **не патчится**: токен и URL сервера лежат рядом в `agent.json` (секрет зашифрован). Установщик и подпись не ломаются. Шаблон из `prebuilt/` / `bin/` без `agent.json` на сервер не отправится.

После `Install.bat` агент сам собирает инвентарь с этого ПК. Лог статуса: `corax-last-run.txt` рядом с EXE и в `%ProgramData%\CORAX\agent\`.

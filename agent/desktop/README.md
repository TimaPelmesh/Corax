# CORAX Agent (Windows 10/11)

Тихий агент инвентаризации. Один EXE: окно настроек и иконка в трее. Крестик прячет окно, выход — из меню трея.

Скачивайте сборку со страницы «Сборка агента» в панели CORAX — токен вшивается в EXE при скачивании. Шаблон из `prebuilt/` / `bin/` без печати токена на сервер не отправится.

Лог статуса: `corax-last-run.txt` рядом с EXE и в `%ProgramData%\CORAX\agent\`.
